Express CRUD API

A simple CRUD API built with Express.js to perform Create, Read, Update, and Delete operations. This project demonstrates REST API concepts, middleware usage, JSON handling, and custom error handling using HttpError.

Features
Create data
Read all or single data
Update existing data
Delete data
Custom error handling
Express middleware support

Tech Stack
Node.js
Express.js
JavaScript (ES Modules)


API Routes
GET /tasklist → Get all tasks
GET /tasklist/:id → Get single task
POST /tasklist → Create task
PUT /tasklist/:id → Update task
DELETE /tasklist/:id → Delete task
